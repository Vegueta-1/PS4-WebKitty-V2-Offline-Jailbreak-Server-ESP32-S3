PS4 Setup Guide
  1. Settings → Network → Set Up Internet Connection → Use Wi‑Fi → Custom
  2. Connect to Exploit‑PS4
  3. Password: password
  4. IP Address Settings → Automatic
  5. DHCP Host Name → Do Not Specify
  6. DNS Settings → Automatic
  7. MTU Settings → Automatic
  8. Proxy Server → Do Not Use
  9. Run Test Connection
  10. Do NOT open the Internet Browser
  11. Open: Settings → User's Guide / Helpful Info → User Guide
About This Project

An offline PS4 jailbreak host based on ArabPixel/WebKitty, ported to the ESP32‑S3 platform for a portable and self‑contained jailbreak solution.

Supports a wide range of PlayStation 4 firmware versions without requiring an internet connection.
