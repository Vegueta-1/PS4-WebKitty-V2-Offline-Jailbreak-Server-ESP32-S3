ESP32-S3 Portable Offline Jailbreak Host

PS4 WebKitty V2 Offline Jailbreak Server

An offline PS4 jailbreak host based on ArabPixel/WebKitty, ported to the ESP32-S3 platform for a portable and self-contained jailbreak solution. Supports a wide range of PlayStation 4 firmware versions without requiring an internet connection.

Flash Firmware Setup Guide
Firmware Installation
⚠ Hardware Specific

This firmware is ONLY for ESP32-S3 N16R8 WROOM-1 devices (16MB Flash / 8MB PSRAM).

Connect your compatible ESP32-S3 board via USB and flash the latest PS4 WebKitty V2 firmware.

Chrome or Microsoft Edge required (Web Serial API).

PS4 Setup Guide
  1. Settings → Network → Set Up Internet Connection → Use Wi‑Fi → Custom
  2. Connect to: Exploit-PS4
  3. Password: password
  4. IP Address Settings → Automatic
  5. DHCP Host Name → Do Not Specify
  6. DNS Settings → Automatic
  7. MTU Settings → Automatic
  8. Proxy Server → Do Not Use
  9. Run Test Connection
  10. Do NOT open the Internet Browser
  11. Open: Settings → User's Guide / Helpful Info → User Guide
About This Project

PS4 WebKitty V2 is an offline exploit host based on ArabPixel/WebKitty and ported to ESP32-S3 hardware to provide a compact, portable, self-contained PS4 jailbreak solution.

Supports PS4 firmware versions 6.7x through 13.52 and includes GoldHEN support for offline operation.

Originally based on ArabPixel/WebKitty
Ported to ESP32-S3 by Vegueta1
