    About This Project
     

    PS4 WebKitty V2 is an offline exploit host based on ArabPixel/WebKitty and ported to ESP32-S3 hardware to provide a compact, portable, self-contained PS4 jailbreak solution.

     

    Supports PS4 firmware versions 6.7x through 13.52 and includes GoldHEN support for offline operation.
